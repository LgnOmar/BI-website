# بوكس مشكاة 🌸 | Mishkat Box Landing Page

صفحة هبوط تسويقية متكاملة وعالية التحويل (High-Converting CRO Landing Page) باللغة العربية (RTL) لمنتج **"بوكس مشكاة"**، وهو رفيق متكامل للمرأة المسلمة في حفظ وتثبيت وتدبر القرآن الكريم، مقدم من **Graphics by BI**.

---

## 🌟 مميزات المشروع (Features)

- **تصميم هادئ وفاخر (Serene & Elegant Theme):**
  - اعتماد اللون البرغندي / العنابي الداكن (`#470923`) كلون أساسي للهوية.
  - لمسات باللون الكريمي الذهبي والوردي الباستيلي الهادئ.
  - خطوط عربية واضحة وأصيلة (Cairo & Amiri من Google Fonts).
- **عرض تفاعلي لمحتويات البوكس الخمسة:**
  1. مفكرة مشكاة الشاملة (3 في 1).
  2. دفتر التكرار والتثبيت المبني على أسلوب التكرار المتباعد (*Spaced Repetition*).
  3. خريطة قلب السور الـ 114 البصرية.
  4. بطاقات تدبر أسماء الله الحسنى مع حامل خشبي.
  5. فواصل مصحفية مغناطيسية راقية.
  - إمكانية معاينة تفاصيل كل مكون عبر نافذة منبثقة (*Modal*).
- **استعراض الفيديو الحقيقي (Video Showcase):** مشغل فيديو مدمج يتيح للزائرات مشاهدة تفاصيل البوكس الحقيقية قبل الشراء.
- **استمارة طلب سريعة ومحسنة للتحويل (CRO Checkout):**
  - قائمة منسدلة تضم **58 ولاية جزائرية كاملة** مع احتساب فوري لتكلفة التوصيل.
  - خيارات التوصيل للمنزل أو استلام من المكتب (*Stop Desk*).
  - تحقق ذكي من أرقام الهواتف الجزائرية (05, 06, 07, 02).
  - شاشة تأكيد فورية مع رقم مرجعي للطلب، قصاصات احتفالية (*Confetti*)، وزر تأكيد مباشر عبر الواتساب.
- **متجاوب 100% مع الهواتف الذكية:** مزود بشريط طلب عائم سفلي (*Sticky Bottom Bar*) مصمم خصيصاً للزائرات القادمات من إعلانات إنستغرام وتيك توك.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 19**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (أيقونات واجهة المستخدم)
- **Canvas Confetti** (تأثيرات بصرية عند إتمام الطلب)

## 🚀 التشغيل والتطوير المحلي (Getting Started)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:5173/`

### 3. بناء نسخة الإنتاج:
```bash
npm run build
```

### 4. معاينة نسخة الإنتاج:
```bash
npm run preview
```
