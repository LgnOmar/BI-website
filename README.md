# بوكس مشكاة 🌸 | صفحة طلب دفع عند الاستلام (COD) فائقة السرعة والتحويل

صفحة هبوط مخصصة لمبيعات الدفع عند الاستلام (*Cash on Delivery*) لمنتج **"بوكس مشكاة"** من **Graphics by BI**. صُممت لتكون فائقة السرعة، متجاوبة 100% مع الهواتف الذكية، ومجهزة بنموذج طلب فوري في أعلى الصفحة بجانب معرض الصور والفيديو، مع ربط مباشر مع **Google Sheets**.

---

## 🌟 مميزات التصميم والتحويل (CRO Highlights)

1. **الترويسة المباشرة (Header):**
   - شعار "مشكاة" وشارة `"التوصيل متوفر لكل 58 ولاية 🇩🇿"`.
2. **منطقة التحويل الرئيسية بأعلى الصفحة (Main Conversion Zone):**
   - **معرض الصور والفيديو (Media Gallery):** عرض سلس للفيديو الحقيقي للبوكس (`box-video.mp4`) مع صور المنتجات الخمسة وشريط صور مصغرة.
   - **بطاقة الطلب السريع (Order Form Card):** بطاقة بارزة ومباشرة بجانب المعرض تمكن الزبونة من الطلب فوراً دون الحاجة للتمرير لأسفل الصفحة.
3. **حقول استمارة الطلب والحساب الديناميكي:**
   - الاسم الكامل
   - رقم الهاتف (مع فحص لأرقام الهاتف الجزائرية: 05، 06، 07، 02)
   - قائمة الـ 58 ولاية جزائرية
   - البلدية
   - خيار مكان الاستلام (توصيل للمنزل أو من المكتب Stop Desk) مع تحديث فوري لتكلفة التوصيل
   - ملخص السعر المباشر: سعر المنتج + التوصيل = المبلغ الإجمالي
   - زر الإرسال مع حالة التحميل وحالة النجاح المبهجة (قصاصات احتفالية Confetti + زر تأكيد فوري عبر الواتساب).
4. **ربط مباشر مع Google Sheets:**
   - إرسال بيانات كل طلب تلقائياً عبر Webhook مجاني وسريع دون الحاجة لخادم backend.
5. **محتوى ثانوي مدمج أسفل الصفحة (Below the fold):**
   - تفاصيل المحتويات الخمسة، آراء المشتركات، والأسئلة الشائعة مع زر سريع للصعود للطلب.

## 📊 خطوات ربط Google Sheets في دقيقتين

تم إعداد ملف جاهز اسمه [`google-script-template.js`](file:///C:/Users/hp/Desktop/Apps/DesignByBI/google-script-template.js):

1. افتح جدول بيانات جديد في Google Sheets.
2. في الصف الأول، ضع العناوين التالية:
   - `A1: التاريخ والوقت`
   - `B1: رقم الطلب`
   - `C1: الاسم الكامل`
   - `D1: رقم الهاتف`
   - `E1: الولاية`
   - `F1: البلدية`
   - `G1: نوع التوصيل`
   - `H1: الكمية`
   - `I1: المجموع الكلي`
   - `J1: ملاحظات`
3. من القائمة العلوية: **إضافات (Extensions) -> Apps Script**.
4. انسخ الكود الموجود في [`google-script-template.js`](file:///C:/Users/hp/Desktop/Apps/DesignByBI/google-script-template.js) والصقه هناك ثم احفظ.
5. اضغط على زر **نشر (Deploy) -> نشر جديد (New deployment)**.
6. اختر نوع التثبيت: **تطبيق ويب (Web app)**:
   - الوصف: `Mishkat COD Webhook`
   - التنفيذ باسم: **حسابي (Me)**
   - من يملك حق الوصول: **أي شخص (Anyone)**  *(ضروري جداً)*
7. اضغط **نشر (Deploy)**، وانسخ رابط تطبيق الويب الناتج.
8. أنشئ ملف `.env.local` في مجلد المشروع وضع فيه الرابط:
   ```env
   VITE_GOOGLE_SHEET_URL=https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec
   ```
