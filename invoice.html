Project Overview & Scope

This invoice covers the complete design, development, and order automation for the Mishkat Box (بوكس مشكاة) Cash on Delivery (COD) landing page. Built with React and Tailwind CSS, the website provides ultra-fast mobile loading, complete integration for all 58 Algerian Wilayas and communes, zero monthly server fees, and automated order logging directly into Google Sheets.
